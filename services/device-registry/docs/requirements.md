# Вимоги до сервісу «Реєстр пристроїв» (services/device-registry) — Команда 1

## 1. Загальний опис
Сервіс призначений для збереження, валідації, оновлення та відображення інформації про мережеві пристрої в симуляторі.

## 2. Модель даних
Кожен пристрій (`Device`) має такі поля:
- `id` (`int`): унікальний ідентифікатор пристрою (> 0).
- `name` (`std::string`): назва пристрою (не порожня).
- `type` (`std::string`): тип пристрою. Дозволені значення: `ROUTER`, `SERVER`, `SENSOR`, `TERMINAL`.
- `online` (`bool`): стан пристрою (`true` — ONLINE, `false` — OFFLINE).

Обмеження: максимальна кількість пристроїв у масиві — `100` (`const int MAX_DEVICES = 100`).

## 3. Функціональні вимоги
1. **Додавання пристрою (`addDevice`)**:
   - Перевірка унікальності `id` (дублікати заборонені).
   - Перевірка коректності типу (`ROUTER`, `SERVER`, `SENSOR`, `TERMINAL`).
   - Перевірка наповненості реєстру (максимум 100 елементів).
2. **Пошук пристрою за ID (`findDeviceById`)**:
   - Повертає індекс пристрою в масиві або `-1`, якщо пристрій відсутній.
3. **Зміна стану (`changeStatus`)**:
   - Оновлення поля `online` за вказаним `id`.
4. **Вивід списку пристроїв (`printDevices`)**:
   - Форматоване виведення у вигляді таблиці.
5. **Статистика (`printStatistics`)**:
   - Підрахунок загальної кількості, кількості ONLINE/OFFLINE та розбивка за типами.
