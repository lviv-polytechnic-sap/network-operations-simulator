# Future Integration

Integration is deliberately outside the first two-week assignment. Do not add sockets, HTTP, shared databases, container networks, or inter-process communication during the initial project.

After the individual services have been defended, the instructor may introduce file-based integration using this conceptual record:

```text
EVENT;id;type;severity;source
```

The concrete rules, parsing, validation, and error handling must be designed as a later assignment. This directory must not become a place for cross-team code during the first cycle.
